Duplicate display: mocks for the displays card

The combined version comes first. A, B and C below are the three separate ideas it was picked from.

A+B

Switch for the usual cases, stacking for the rest

The switch is a shortcut that writes the same state stacking does. Duplicate stacks every display, Extend pulls every stack apart. Arrow keys move the switch, so a projector needs no pointer: open, →, Enter.

Against
