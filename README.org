#+title: NixOS & Home Manager Configuration
#+author: Oskar Haukebøe

Personal NixOS and Home Manager configuration using flakes, supporting multiple systems and machines. Every machine currently runs NixOS, and that is the only setup that is tested. The flake still exports standalone ~homeConfigurations~ (Linux and macOS), but running them outside NixOS is unmaintained and has no setup instructions. This repo started out as just an Emacs config, hence the repo name, which is written in literate org-mode [[file:workstation/emacs/config.org][here]].

* Quick Start

** NixOS System
#+begin_src sh
sudo nixos-rebuild switch
#+end_src

~/etc/nixos/flake.nix~ is symlinked to this checkout (see ~system.flakePath~), so
~nixos-rebuild~ finds the flake on its own and takes the attribute from the
hostname. The fish alias ~nrs~ does the same. To rebuild a *different* machine,
or from a checkout that is not the symlinked one, be explicit:

#+begin_src sh
sudo nixos-rebuild switch --flake .#<hostname>
#+end_src

Where ~<hostname>~ is one of the machines in [[file:machines/machines.nix][machines/machines.nix]]: ~x13-laptop~,
~work-laptop~, or ~desktop~.

** New Machine

Installing on fresh hardware is a separate procedure — see
[[file:docs/new-machine.md][docs/new-machine.md]]. Two of its steps (putting firmware into Secure Boot
Setup Mode, and setting a password before the first reboot) leave you with an
unusable install if skipped, so read it through first.

* Features

- NixOS machines (x86_64-linux); standalone Home Manager outputs for x86_64-linux, aarch64-linux and aarch64-darwin (untested)
- Literate Emacs configuration in org-mode
- COSMIC desktop environment on NixOS
- Rootless Docker and Podman
- SOPS (age) for secrets, git-agecrypt for low-sensitivity private files (same age keys)
- Fish shell with starship, zoxide, and atuin
- AI coding assistants (Claude Code, Goose, OpenCode)

* Boot

The ~silent-boot~ module (on by default) shows an animated NixOS Plymouth splash
([[https://github.com/SergioRibera/s4rchiso-plymouth-theme][mac-style]] theme), hides kernel output, and hides the systemd-boot menu.

- Show the boot menu: hold (or repeatedly tap) =Space= while the machine powers on.
- Show it on the next boot only, from a running system: ~sudo bootctl set-timeout-oneshot 10~
- Show boot messages behind the splash: press =Esc= during boot.
- Disable for a machine: ~{ modules.silent-boot.enable = false; }~ in ~machines/machines.nix~,
  or only the early GPU driver loading with ~modules.silent-boot.earlyKms.enable = false~.

* Gaming

~modules.gaming~ (enabled on ~desktop~) sets up Steam with GE-Proton, Proton's Wayland driver and
GameMode. Design: ~specs/008-game-performance-tuning/~. Measured decisions (stock kernel, GPU power
limit 290 W, GameMode for Factorio): ~docs/gaming-benchmarks.md~.

- GameMode for a game: set its launch options to ~gamemoderun %command%~ (a global preload breaks
  the Steam client).
- Compare Zen against stock again: set ~boot.kernelPackages~ back to Zen and turn on
  ~modules.gaming.kernelComparison.enable~; it adds a boot entry tagged ~stock~.

** Benchmarking

~game-bench~ compares tunings (schedulers, CPU and GPU power settings, Proton options) with repeated,
unattended runs of a game's built-in benchmark, and restores every setting afterwards.

1. Set the game's launch options to ~game-bench-wrap %command%~ (outside a session it changes nothing).
2. Run a session from a terminal, for example:

#+begin_src sh
game-bench list
game-bench run -w cyberpunk -v "baseline gamemode scx-bpfland" -n 5
game-bench compare ~/.local/share/game-bench/<session> ~/.local/share/game-bench/<session>
#+end_src

Setup and the full procedure: ~specs/008-game-performance-tuning/quickstart.md~. Results and
decisions: ~docs/gaming-benchmarks.md~.

* Structure

- ~flake.nix~ - Main entry point
- ~workstation/~ - Home Manager user configuration
- ~machines/~ - Per-machine configurations and the machine registry
- ~modules/~ - Optional feature modules (gaming, cosmic-de, secure-boot, sshd, silent-boot, ...)
- ~common/~ - Shared NixOS defaults, caches, custom options, unfree predicates
- ~lib/~ - Helper functions and the shared disko disk layout
- ~just/~ - just recipes (bootstrap, sops, nvfetcher, git-agecrypt, new-machine)
- ~docs/~ - Runbooks and architecture decision records
